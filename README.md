# Powder Keg (working title)

A pausable grand strategy game where every nation is a countryball. The clock
starts in 1914 or 1936, and the player's decisions push history off its real
course. Story events depend on what has already happened, so different choices
produce different timelines.

## Status

Concept stage. No game code yet.

- `concept/powder-keg.html` is the design overview and an interactive sketch of
  one game screen (June 1914, playing as Germany). It is written as page
  content without `<html>`/`<body>` wrappers, as published to a Claude artifact;
  browsers still open it directly.

## Planned stages

1. A playable 1914: map of Europe, clock, five playable powers, telegrams,
   diplomacy, the Chronicle newspaper, story and Fate cards.
2. The war: armies and fronts, factories, research, the Treaty table.
3. 1936, including carrying a finished 1914 world forward.
4. Polish: saves, sound, the timeline-versus-real-history end screen.
