POWDER KEG FOR iPHONE AND iPAD

This folder is an app project: a thin wrapper that shows the game page full screen.
It builds for the iPhone simulator with Xcode 16 (checked automatically on GitHub).
It has not yet been run on a real device.

On an iPad, no Mac needed
  1. Install "Swift Playgrounds" from the App Store (free).
  2. Put the PowderKeg.swiftpm folder in the Files app (iCloud Drive or On My iPad).
  3. Tap it. It opens in Swift Playgrounds. Press the Play button.
  The game runs full screen. It stays in Swift Playgrounds' list of apps.

On a Mac, to install on an iPhone or iPad
  1. Install Xcode from the App Store (free).
  2. Double-click PowderKeg.swiftpm.
  3. In the project settings choose your Apple ID as the Team.
  4. Plug in the phone or tablet, pick it at the top of the window, press Run.
  With a free Apple ID the app must be re-installed every seven days.
  A paid developer account removes that limit.

The game page is Resources/index.html. Replacing that file updates the game.
The typefaces load from the internet; with no connection the game uses the device's own serif face.
